# GSM4 插件系统（首版）

## 能力范围

首版插件系统提供一条可实际使用的完整链路：

- 扫描 `data/plugins/<plugin-name>/plugin.json`
- 展示插件元数据和损坏目录原因
- 管理员启用、禁用和卸载插件
- 从插件页安装 `gsm4-example` 官方示例
- 在沙箱 iframe 中打开已启用插件的 WebUI
- 通过受控消息接口读取系统信息、实例列表并启停实例

首版**不会执行插件目录中的 Node.js 服务端代码**。插件只能提供静态 WebUI，并通过面板公开的消息接口调用能力，避免插件在服务端进程内获得任意代码执行权限。

## 目录结构

```text
data/plugins/
└── my-plugin/
    ├── plugin.json
    ├── index.html
    └── assets/
        ├── app.js
        └── style.css
```

插件目录名必须与 `plugin.json` 的 `name` 一致，只允许字母、数字、下划线和连字符。

## plugin.json

```json
{
  "name": "my-plugin",
  "displayName": "我的插件",
  "description": "插件说明",
  "version": "1.0.0",
  "author": "开发者",
  "enabled": false,
  "hasWebInterface": true,
  "entryPoint": "index.html",
  "icon": "puzzle",
  "category": "工具",
  "apiVersion": 1
}
```

启用状态直接原子写回该文件；清单中的未知扩展字段会被保留。入口路径只能指向插件目录内的 HTML 文件，符号链接和目录穿越会被拒绝。

## 面板接口

所有管理接口均要求 Bearer Token，变更操作仅允许管理员：

| 方法 | 路径 | 用途 |
|------|------|------|
| `GET` | `/api/v1/plugins` | 获取插件和损坏目录列表 |
| `POST` | `/api/v1/plugins/refresh` | 重新扫描插件目录 |
| `POST` | `/api/v1/plugins/example` | 安装官方示例插件 |
| `PATCH` | `/api/v1/plugins/:name` | 设置 `enabled` |
| `DELETE` | `/api/v1/plugins/:name` | 卸载插件目录 |

已启用插件的允许类型静态资源通过 `/plugin-ui/:name/*` 提供。该地址不承载面板 Token，插件也无法读取 `localStorage`。

## iframe 消息接口

插件页面从查询参数读取 `channel`，然后向父页面发送请求：

```javascript
window.parent.postMessage({
  type: 'gsm4:plugin:request',
  channel,
  requestId: crypto.randomUUID(),
  action: 'instances.list',
  payload: {}
}, '*')
```

父页面返回：

```javascript
{
  type: 'gsm4:plugin:response',
  channel,
  requestId,
  ok: true,
  data: []
}
```

首版允许的 action：

- `context.get`
- `system.info`
- `system.stats`
- `instances.list`
- `instances.start`
- `instances.stop`
- `instances.restart`

插件还可发送 `gsm4:plugin:notify` 调用面板消息组件，或发送 `gsm4:plugin:close` 关闭 WebUI 弹窗。

## 安全约束

- iframe 使用 `sandbox`，不授予 `allow-same-origin`
- 面板只接受当前 iframe、当前随机 channel 的消息
- Token 永远不发送给插件
- WebUI 响应带严格 CSP，禁止直连网络、表单提交、对象嵌入和嵌套 frame
- 静态资源使用扩展名白名单，不提供 JSON、TXT、配置文件和隐藏文件
- 所有资源路径执行目录包含校验和符号链接逃逸校验
- 插件由管理员安装并视为受信代码；生产环境仍应审查插件源文件
