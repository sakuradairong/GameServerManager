# M2 验收说明（DeploySession）

## 快乐路径

### 1. 文件归档（自动化优先）

1. 准备可公网或本机 `http://127.0.0.1` 可达的 zip  
2. `POST /api/v1/deploy`：

```json
{
  "type": "archive",
  "instanceName": "archive-demo",
  "installName": "archive-demo",
  "archiveUrl": "http://127.0.0.1:8765/demo.zip",
  "startCommand": "./start.sh"
}
```

3. 订阅 Socket `deploy:progress` / `deploy:log` / `deploy:complete`  
4. 成功后 `GET /api/v1/instances` 可见实例；失败则实例被回滚删除

### 2. Minecraft

同流程，`type: "minecraft"`，提供 jar URL；成功后目录内有 jar + `eula.txt`。

### 3. SteamCMD

1. 在 `data/config.json` 设置 `steamcmd.path` 为可执行文件  
2. `type: "steamcmd"` + catalog 中的 `gameKey` / `appId`  
3. 未配置路径时应失败，并回滚草稿实例（验证错误路径）

## 取消

`POST /api/v1/deploy/cancel` body `{ "sessionId": "..." }`  
或 Socket 事件 `deploy:cancel`。下载类执行器响应 AbortSignal。
