## 一句话结论

- **GSM3**：`main` 继续维护与热修  
- **GSM4**：长期线 `gsm4/main`（**orphan 空根**），按里程碑推进  
- **兼容**：不保证 API 逐接口兼容；提供一次性迁移工具  
- **核心纠偏**：统一 `DeploySession` + 域模块化，消灭多管道复制与上帝文件

## 推荐推进顺序

1. 评审并冻结本目录方案  
2. 创建 orphan 分支 `gsm4/main`，只提交 GSM4 骨架（不含 GSM3 树）  
3. 按 [03-里程碑](./03-里程碑.md) 从 M0 开始实现  
4. 每个里程碑用短生命周期分支 `cursor/gsm4-mN-*-316b` 合入 `gsm4/main`
