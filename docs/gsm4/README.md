## 一句话结论

- **GSM3**：`main` 继续维护与热修  
- **GSM4**：长期线 `gsm4/main`（**orphan 空根**），按里程碑推进  
- **兼容**：不保证 API 逐接口兼容；提供一次性迁移工具  
- **核心纠偏**：统一 `DeploySession` + 域模块化，消灭多管道复制与上帝文件

## 当前推进顺序

1. 保持 M0–M3 的统一 DeploySession、认证和实时通信契约
2. **M4**：备份、定时任务、环境管理（当前主线）
3. **M5 余量** / **M6**：migrator、发布产物、对照表关闭
4. 新入口只在功能完整可用后加入导航
5. 每个交付执行 [06-安全与发布门禁](./06-安全与发布门禁.md)
