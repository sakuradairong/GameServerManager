## 当前重点（执行顺序）

依据 [09-竞品调研](./09-竞品调研.md) 的能力矩阵：

1. **M4**：定时任务 → 文件压缩/收藏 → Java/系统环境（备份已交付）
2. **安全边界**：持续符合 [06-安全与发布门禁](./06-安全与发布门禁.md)
3. **M5 余量**：RCON、多用户 ACL、EasyTier、实例市场、gameconfig 等（插件首版已完成）
4. **M6**：`packages/migrator`、多架构发布产物、功能对照表关闭

原则：**功能完整可用后再加入导航**，不保留空占位页（插件首版已满足此条件）。**不对齐** Docker eggs / 强制隔离（见竞品调研定位声明）。
