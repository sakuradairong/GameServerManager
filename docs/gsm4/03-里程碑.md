# GSM4 里程碑

原则：**每个里程碑结束时面板可启动、可演示该阶段能力**；不把未完成域的半截代码留在主路径上。

工作分支命名：`cursor/gsm4-m<N>-<topic>-316b` → PR 基线 **`gsm4/main`**（orphan）。  
方案文档本身可先合入 `main`。

---

## M0 — 骨架与壳

**目标**：空面板可登录，工程可构建。

### 交付

- orphan `gsm4/main` 初始化（若尚未创建）
- npm workspaces：`apps/web`、`apps/server`、`packages/shared`
- Fastify 健康检查 + 基础日志
- 用户注册（首用户）/ 登录 / JWT 中间件
- `config` 域最小实现 + `data/manifest.json`
- Web：登录页 + 布局导航壳（各页占位）
- 统一错误形状、ApiClient 雏形
- Docker 开发/运行草稿
- GSM4 版 `AGENTS.md`、根 `README.md`

### 完成标准

- `apps/server` / `apps/web` 可 `dev` / `build`
- 无 token 无法访问受保护 API
- 导航可切换占位页

## M1 — 终端 + 实例 + 监控

**目标**：日常运维最小闭环（不管部署）。

### 交付

- PTY adapter（复用/移植二进制策略，接口新写）
- 终端多会话：创建、输入、resize、关闭、重连
- 实例 CRUD、启动/停止/重启、操作锁
- Home：CPU/内存/磁盘等基础系统信息
- 实例与终端关联（按需附着会话）

### 完成标准

- 能在面板打开终端执行命令
- 能手动添加实例并启停（命令型进程）
- 刷新后实例仍在（`instances.json`）

---

## M2 — 部署内核（核心纠偏）

**目标**：一条 `DeploySession` 跑通三类执行器。

### 交付

- `deploy` 域：Session / ProgressBus / Validator / InstanceCommit
- Executors：`steamcmd`、`minecraft`、`archive`
- `catalog`：`installgame.json` 读写与远程同步（路径解析统一）
- Web：`features/deploy` 三子页（非单文件巨页）
- 统一实时事件 `deploy:*`
- 取消安装（至少 download/archive；Steam 定义可取消边界）

### 完成标准

- Steam / MC / 压缩包 各至少一条快乐路径文档化验收
- 成功写入/更新 Instance；失败回滚策略可演示
- 前后端 cancel 契约一致（shared schema）

---

## M3 — 部署扩展

**目标**：补齐其余部署入口，全部复用 M2 内核。

### 交付

- Executors：`mrpack`、`bedrock`、`tmodloader`、`factorio`
- 平台能力表驱动 UI 显隐
- Steam 更新 / 分支选择（实例侧入口可放 instances feature）

### 明确不做 / 暂缓

- **云构建 `cloud`**：不做。上游工具未开放；曾短暂实现后已删除（`cloudExecutor`、`cloudBuild` 路由与 Web 面板）。遗留 `instanceType: cloud` 在加载时迁移为 `generic`。
- **赞助校验 / `online` 在线部署**：暂缓（不接赞助 Key、不移植 GSM3 online 入口）

### 进度（M3）— 已完成

- [x] 能力表驱动 Deploy 页签显隐（`GET /api/v1/deploy/capabilities` 返回 platform + available）
- [x] Executors：`bedrock`、`tmodloader`
- [x] Executors：`mrpack`（Modrinth 整合包：按 `files[].path` 落盘 + hash 校验 + overrides/server-overrides + 加载器安装 + 写 `eula=true`）
- [x] Executors：`factorio`（官方 headless linux64 tar.xz：`xz`+`tar` 安全解压 + 生成初始存档 + `--start-server-load-latest`）
- [x] Steam 更新 / 分支选择（通过 SteamCMD 查询账号可见分支，部署与实例更新均支持 beta 分支密码；实例侧 `POST /api/v1/instances/:id/steam/update` 复用 steamcmd 执行器与 `deploy:*` 进度，成功写回 `steam.branch`）
- [x] ARM 上 Steam 相关入口按能力表隐藏（`linux_arm` 不包含 steamcmd）

### 完成标准

- 无新的「独立进度事件族」分叉
- ARM 上 Steam/相关入口按能力表隐藏

## 里程碑之间的规则

1. **禁止提前堆砌未计划域的上帝文件**「先写着以后再拆」。  
2. 契约变更（事件名、DTO）必须先改 `packages/shared` + 本目录文档。  
3. GSM3 `main` 仅接受：方案文档、以及与 GSM4 无关的热修。  
4. 若某里程碑过大，拆成 `M2a/M2b`，但不得跳过 M2 直接做 M3 执行器分叉实现。
